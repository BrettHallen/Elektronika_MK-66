# Elektronika MK-66<br>Электроника МК-66
Information about the Soviet-era engineering "microcalculator".<br>

Processor: [К145ИП16Б](/K145IP16B/)<br>
Display: [ИЛЦ2-12/8Л](/ILC2-12_8L)<br>
Keypad: 5x5 metal-dome matrix<br>

## Keypad Layout

The MK-66 has 25 keys in a 5 × 5 matrix, plus two slide switches above the keys. Each key has a **primary function**, printed on the key, and a *second function*, printed on the panel above it. To use a second function, press **F** first, then the key.

### Switches

| Position | Marking | Function |
|:--|:--|:--|
| Left | `•` | **Power**: slide right (towards the dot) for on, left for off |
| Right | `Г` / `Р` | **Angle mode**: Г = degrees (*градусы*), Р = radians (*радианы*). MK-66 only; the MK-66A works in degrees only |

### Key reference

| Marking | Russian | English | Notes |
|:--|:--|:--|:--|
| **C** | — | Clear | Once: clears overflow. In F mode, press 3×: cancel F, clear display, clear constant register. Does not clear memory |
| *CF* | — | Cancel F | Leaves dual-function mode |
| **/-/** | — | Change sign (+/−) | Changes the sign of the mantissa, or of the exponent after **ВП** |
| *1/X* | — | Reciprocal | |
| **arc** | — | Inverse trig prefix | **arc** then *sin*, *cos* or *tg* gives arcsin, arccos, arctan |
| **ВП** | *Ввод порядка*, "enter exponent" | EE / EXP | |
| **F** | — | Function (shift) | Selects the second function of the next key |
| **[(** / **)]** | — | Brackets | Two levels of nesting |
| *ЗП* | *Запись в память*, "write to memory" | MS (memory store) | |
| *СП* | *Сброс памяти*, "reset memory" | MC (memory clear) | |
| *ИП* | *Извлечение из памяти*, "recall from memory" | MR (memory recall) | |
| *П+ П− П× П÷* | П = *Память*, "memory" | M+ M− M× M÷ | Result goes to memory; display is unchanged |
| *Х↔П* | *Обмен Х с памятью*, "exchange X with memory" | X↔M | Swaps display and memory |
| **↔** | — | X↔Y | Swaps display and constant (operand) register |
| *tg* | *Тангенс* | tan | |
| *lg* | *Десятичный логарифм* | log₁₀ | |
| *Р→Г* | *Радианы → Градусы* | rad → deg | |
| *Г→Р* | *Градусы → Радианы* | deg → rad | |
| **π** | — | Pi | Displays 3.1415926 |
| *n!* | — | Factorial | Integers 1–69; n = 69 takes up to 10 s |

> **Note:** Key and switch markings are transcribed from an MK-66 unit. The MK-66A works in degrees only, so its trig functions don't use a Г/Р setting.
